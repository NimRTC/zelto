# Slice: v3-help-system

## 目的

将现有帮助系统重构为 L1（顶层概览）→ L2（命令级说明）→ L3（参数/选项级详解）三层结构：只改动 `src/cli/commands/info-help.ts` 与 `src/cli/commands/catalog.ts`，实现按组展示的概览、命令级与参数级的逐层下钻、`--all` 全量展开、层级返回与检索、以及与当前层级自适应的 `--help`/`-h`，同时扩展 catalog 组的索引使其可被帮助系统检索，保证既有帮助信息不丢失。

## 范围

要改的（这些是 agent 会去改的文件）：
- `src/cli/commands/info-help.ts`
- `src/cli/commands/catalog.ts`

只读参考（**不得修改**，agent 只许读）：
- 只读 `src/cli/index.ts` —— 帮助命令的调用入口与 `--help`/`-h` 的接入点在这里，`src/cli/commands/info-help.ts` 需要与它的调用方式兼容；同时它也是 L1 概览如何暴露给用户的对接参考。

## 需求

无（本片没有关联的需求条目，验收标准需人补齐后再确认规格）。

## 验收标准

1. 实现三层帮助结构：默认入口输出 L1 顶层概览，按组展示命令；进入具体命令后输出 L2 命令级说明（命令名、用途、用法行、选项列表）；进入具体参数后输出 L3 参数级详解（参数名、描述、约束/默认值）；验证方式：以三个层级分别调用帮助渲染逻辑，单测断言对应输出分别包含组标题、命令名+用法行、参数名+描述。
2. L1 顶层概览默认仅显示「核心切片组」与「项目管理组」两个组的命令；验证方式：构造包含上述两组之外第三组数据的 catalog，单测断言不带额外参数的概览输出不含第三组的组标题及其命令名。
3. 支持 `--all` 展开全部层级与全部命令：`--all` 输出包含所有组的条目，且每个命令条目均含到 L3 参数级的信息；验证方式：在步骤 2 的同一数据上，单测断言 `--all` 输出包含第三组的标题、命令名及其每个参数名。
4. 支持按层级定位参数：按 `group/command/parameter` 形式的定位路径可从顶层直达 L3；支持 `..` 返回上层、`top` 返回顶层；验证方式：对定位解析函数做单测，断言 `["core","cmd1","--opt"]` 落到 L3 参数，`[".."]` 落到 L2，`["top"]` 落到 L1。
5. `--help` 与 `-h` 输出与当前层级自适应：在 L1 传 `--help` 显示顶层概览的帮助提示，在 L2 显示当前命令的说明，在 L3 显示当前参数的详解；验证方式：对同一调用入口分别以 L1/L2/L3 当前层级传入 `--help`，单测断言输出分别等于对应层级的帮助文本；再以 `-h` 重复断言。
6. 扩展 catalog 组索引：`catalog.ts` 提供可被帮助系统按组查询的索引结构，使 catalog 组的命令能出现在 L1 概览与 `--all` 展开中，并能通过按层级定位访问到 catalog 的命令与参数；验证方式：单测调用索引查询函数，断言能取回 catalog 组条目；默认概览与 `--all` 输出中均包含 catalog 组；按 `catalog/<子命令>/<参数>` 定位能返回对应内容。
7. 不丢失任何既有帮助信息：以重构前的 `src/cli/commands/info-help.ts` 中出现的全部命令名与选项标识符为基准集合，新实现生成的帮助内容必须包含该集合的每一个元素；验证方式：写一个对照单测，从旧文件内容（或 v2 已有的帮助数据快照）提取命令/选项标识符集合，断言新输出中包含该集合的每一个标识符。
8. 当数据不完整或检索目标不存在时给出可识别的提示，且不崩溃；验证方式：单测传入不存在的组、命令、参数路径，断言返回非空错误提示且进程退出码为 0。

## 风险

- 既有帮助信息可能分散在 `src/cli/commands/` 下各命令文件的 usage 字符串中，而本片写集仅含两个目标文件，「不丢失任何已覆盖的有效信息」的盘点工作容易遗漏；应对：先以旧 `src/cli/commands/info-help.ts` 与 `src/cli/commands/catalog.ts` 中现存的文本为基准建立标识符清单，再对照新结构逐条迁移，清单作为单测的对照数据固化。
- 只读 `src/cli/index.ts` 是只读的，若现有调用入口的签名与三层结构不匹配，无法修改接线；应对：在 `src/cli/commands/info-help.ts` 内部完成层级判定与 `--help`/`-h` 的适配，保持对只读 `src/cli/index.ts` 的既有出口兼容，不引入新的依赖。
- `src/cli/commands/catalog.ts` 现有结构未必包含「组索引」概念，扩展时可能影响既有 catalog 命令的输出格式或既有调用方；应对：只在既有数据结构上新增索引函数/字段，保持原输出与既有返回类型不变，并通过原有 catalog 相关测试确认无回归。
